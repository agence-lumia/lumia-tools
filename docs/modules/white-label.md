# Module WhiteLabel

`includes/Modules/WhiteLabel/` — `Module.php` et `MenuProfileManager.php`. Réglages sous `lumia_module_white_label`.

Quatre préoccupations dans un seul module (toutes dans `Module.php` sauf les profils de menu), chacune branchée uniquement quand son groupe de réglages est actif :

- **Barre d'admin / pied de page** : chaque bascule des réglages `admin_bar`/`footer` enregistre conditionnellement son propre hook `admin_bar_menu`/`admin_head`/`gettext`/`show_admin_bar` dans `init()` — rien n'est branché tant que le réglage correspondant n'est pas activé.
- **Nettoyage de la page de profil** (réglages `profile`) : si une bascule `profile.*` est active, un hook `admin_head` (`clean_profile_page()`) injecte du CSS sur `profile.php`/`user-edit.php` pour masquer les sections du cœur choisies (jeu de couleurs, raccourcis clavier, bascule de la barre d'outils, mots de passe d'application, langue, bio, sessions, options d'éditeur). Masquage visuel uniquement — les fonctionnalités restent intactes côté serveur. Cible les classes stables des `<tr>`/sections du cœur plutôt que `remove_action` (les enregistrements varient selon la version de WP).
- **Avatars locaux** (réglage `avatars.local`) : quand actif, un filtre `get_avatar_data` (`apply_local_avatar()`) substitue l'image téléversée par l'utilisateur ; un champ media-picker est rendu sur le formulaire de profil via `personal_options` et enregistré dans la méta utilisateur `lumia_local_avatar` (déclarée dans `get_uninstall_keys()`). Pas de méta d'avatar → WordPress retombe sur Gravatar. La ligne native « Image de profil » (Gravatar) est masquée par CSS via `admin_head`.
- **Stockage des profils de menu** (`MenuProfileManager.php`) : couche CRUD/résolution statique, indépendante des réglages, stockée sous sa propre option `lumia_wl_menu_profiles` (pas `lumia_module_white_label`). `get_active_for_user()` résout le profil actif de plus haute priorité par utilisateur (include_users > include_roles > apply_to_all, les exclusions l'emportent toujours, égalité départagée par `updated_at`) et met le résultat en cache dans un transient par utilisateur (`lumia_wl_menu_user_{gen}_{id}`, TTL 1 h). `{gen}` est une **génération** stockée dans l'option `lumia_wl_menu_cache_gen` : `clear_all_cache()` l'incrémente au lieu de boucler sur les utilisateurs (l'ancienne boucle était plafonnée à 500 comptes, au-delà desquels les autres gardaient un profil périmé). Appeler `clear_user_cache()`/`clear_all_cache()` après toute mutation de profil. Cette classe est consommée par le module **MenuCreator**, pas par le `Module.php` de WhiteLabel.

**« Howdy »** : retiré en réécrivant le nœud `my-account` sur `admin_bar_menu` (préfixe traduit de `Howdy, %s` retranché du titre), pas via `gettext`, qui s'exécutait pour chaque chaîne de chaque page.
